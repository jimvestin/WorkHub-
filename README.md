## Gemensam design

Vi har anpassat våra delar efter gruppens gemensamma färgschema med grönt, beige och sandfärger.

Vi har använt samma typsnitt samt CSS Grid och Flexbox för layouten.

## Inspirationskälla

Vi har hämtat inspiration från [Ästad Vingård](https://astadvingard.se/) och anpassat upplägget och designen till vårt eget WorkHub-projekt.

## Git och GitHub

Vi har arbetat i separata branches, gjort commits och pushat våra ändringar till GitHub. Vi har även använt Pull Requests och hanterat merge-konflikter när vi sammanfört våra delar till `main`.
